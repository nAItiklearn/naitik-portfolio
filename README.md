# Naitik's Portfolio

> A premium, cinematic personal portfolio — built from scratch using vanilla HTML, CSS, and JavaScript.

**Live at:** _[your-url-here]_

---

## 🚀 What's Inside

| Section | Description |
|---|---|
| **Hero** | Full-screen red grid with floating cutout images, bold NAITIK title |
| **About** | Scroll-pinned rotating panels — 4 chapters about who I am |
| **I Love Movies** | Animated horizontal movie poster strip |
| **Projects** | Stack-card animation showcasing my 4 CS projects |
| **Some Designs** | GSAP-powered circular rotating poster wheel |
| **What I Can Do** | Skills grid — Code, ML, Design, Growing |
| **Wanna Be Friends?** | Contact form + live drawing canvas |

---

## 🛠 Tech Stack

- **HTML5** — semantic, no frameworks
- **CSS** — custom design system with tokens, dark/light sections
- **JavaScript** — GSAP, ScrollTrigger, Lenis smooth scroll, Draggable
- **Fonts** — Black Han Sans, Playfair Display, Montserrat, Inter

---

## 📁 Project Structure

```
naitik-port/
├── index.html                  ← Main portfolio page
├── css/                        ← Modular stylesheets
│   ├── tokens.css              ← Design tokens (colors, spacing, fonts)
│   ├── reset.css               ← CSS reset
│   ├── nav.css
│   ├── hero.css
│   ├── about.css
│   ├── work.css                ← Movies section
│   ├── projects.css
│   ├── designs.css
│   ├── skills.css
│   ├── contact.css
│   └── marquee.css
├── js/                         ← Section-specific scripts
│   ├── main.js                 ← Lenis + GSAP init, nav logic
│   ├── hero.js
│   ├── about.js                ← Scroll panel animation
│   ├── work.js                 ← Movie poster strip
│   ├── projects.js             ← Stack card animation
│   ├── designs.js              ← GSAP circle/draggable
│   └── contact.js              ← Canvas drawing tool + form
└── components/                 ← Assets by section
    ├── hero-sec/               ← Hero cutout images + background
    ├── moviesposter-animation/ ← Movie poster images
    └── project-showcase/       ← Project screenshots + design posters
```

---

## ✨ Features

- Smooth scroll via **Lenis**
- Scroll-pinned panel animations via **GSAP ScrollTrigger**
- Draggable circular poster wheel
- Drag-to-rearrange hero images
- Live HTML5 canvas drawing in the contact section
- Fully responsive
